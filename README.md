# 대학생 탐정단

Unity **6000.3.23f1** · PC 2D · 4인 Relay 멀티플레이 · Vivox 음성

## 실행

1. Unity Hub에서 `Assets`, `Packages`, `ProjectSettings`가 있는 폴더를 엽니다.
2. 패키지 설치·컴파일 후 `Assets/Scenes/CapRelayTest.unity`를 더블클릭합니다. `CAP > 게임 씬 열기`로도 열 수 있습니다.
3. Play → 방 만들기 또는 참가 코드 입력 → 전원 준비 → 방장 게임 시작 순서로 진행합니다.

마을은 실행 중 코드로 생성하므로 편집 중인 씬에는 보이지 않습니다. 기본 조작은 WASD 이동, E 문, M 지도, B 자전거, V 눌러서 말하기, N 마이크 음소거, Enter 일반 채팅, Esc 옵션입니다. 사건 조사·보고서 기능은 아직 구현하지 않았습니다.

## 미니맵

월드 화면 오른쪽 위의 원형 미니맵은 내 캐릭터를 중심으로 주변 지도를 표시합니다. 북쪽은 항상 위쪽이며, 흰 테두리와 방향 표시가 있는 점이 내 캐릭터입니다. 주변 플레이어는 각자의 색으로 표시됩니다. 이동 경로는 표시하지 않고 현재 위치만 표시합니다. 회의실에서는 실내 위치를 표시합니다.

방장의 **대기실로 돌아가기** 버튼은 미니맵 바로 아래에 있습니다. **M**으로 여는 전체 지도는 그대로 사용할 수 있습니다.

## 경찰서 NPC 대화

경찰서 건물 정문 앞의 경찰관에게 가까이 가서 **E**를 누르면 대화합니다. **E / Enter** 또는 **다음** 버튼으로 대사를 넘기고, 글자가 나오는 중에 누르면 전체 문장을 표시합니다. 마지막 문장에서 다음을 누르거나 **Esc / ×**로 닫으면 대화가 끝납니다. 대화 중에는 이동·자전거·지도·문 상호작용이 잠깁니다.

다른 플레이어가 대화 중인 NPC에게 말을 걸면 **지금 대화할 수 없습니다** 창이 뜹니다. 방장이 대화 권한을 판정하므로 동시에 요청해도 한 명만 대화할 수 있습니다. 대화 종료, 대기실 복귀, 연결 종료 시 다시 대화할 수 있습니다.

**CAP > 경찰서 NPC 설정** 또는 `Assets/Resources/Dialogue/PoliceNpc.asset`을 선택하면 Inspector에서 교체할 수 있습니다.

- **World Sprite**: 월드 캐릭터 이미지. 가져온 이미지의 Texture Type을 `Sprite (2D and UI)`로 설정한 뒤 연결합니다.
- **Portrait**: 대화창 오른쪽 초상화 PNG 이미지입니다. 투명 배경을 사용할 수 있습니다.
- **World Height**: 월드 캐릭터 키. 이미지 크기와 피벗에 관계없이 발 위치를 유지합니다.
- **Display Name / Lines**: 표시 이름과 순서대로 나오는 대사입니다.
- **Interaction Distance**: 대화를 시작할 수 있는 거리입니다.

이미지를 비워 두면 기본 경찰관 도형이 표시됩니다. 설정은 Play를 끈 상태에서 수정하면 저장되며, 실행 중 이미지를 바꾸면 화면에 즉시 반영됩니다. 멀티플레이 참여자는 모두 같은 새 빌드를 사용해야 합니다(네트워크 버전 7).

## 플레이와 소통

- 플레이어끼리는 겹칠 수 있고 각자 화면에서 자기 캐릭터와 이름표가 가장 위에 표시됩니다. 건물·벽 충돌은 유지합니다.
- 전원 준비 후 방장이 시작을 누르면 카운트다운 없이 즉시 회의실에서 시작합니다. 게임 진행 중에는 새 참가를 거절합니다. 전원이 대기실로 돌아오면 다시 참가할 수 있습니다.
- 머리 위 이름은 대기실에서 설정한 이름과 P 번호를 사용합니다.
- 채팅창은 평소 흐린 반투명으로 보이고 입력 중에는 진하게 표시합니다. Enter로 일반 채팅을 열고 Enter / 전송 버튼으로 보냅니다. Esc는 입력 취소입니다. 입력 중에는 이동·상호작용·음성 송출이 잠깁니다. 같은 방 전체(마을·회의실 포함)에 전달되며 최대 160자, 최근 100개를 보관하고 방을 나가면 비웁니다.
- 우측 하단 마이크 아이콘은 빨강+빗금이면 음소거, 초록이면 송출 중, 회색이면 대기 상태입니다. 클릭 또는 N으로 음소거를 전환합니다. 눌러서 말하기는 V를 누르는 동안 송출합니다.
- Esc로 옵션과 조작키 설정을 엽니다. 지도·대화창·프로필을 열었다면 첫 Esc는 그 창을 닫습니다. 옵션의 **방 나가기**로 게임 도중 나갈 수 있습니다. 방장이 나가면 방도 종료됩니다.

## 빌드와 공유

`CAP > Windows 빌드`로 `Builds/Game/cap.exe`를 만듭니다. 친구에게는 `Builds/Game` 폴더 전체를 전달합니다. 빌드 후 접속 → 전원 준비 → 방장 시작 → 마을·회의실 이동 → 대기실 복귀를 확인합니다.

작업 전 Pull, 작업 후 저장 → Commit → Push를 진행합니다. 다른 사람도 Pull해야 변경을 받습니다. 에셋 이동은 Unity Project 창에서 하고 `.meta`를 유지합니다. `Assets/DefaultNetworkPrefabs.asset`는 Netcode가 사용하는 등록 목록이므로 삭제하지 않습니다. `Library`, `Builds`, `Logs`, `UserSettings`는 자동 생성되므로 Git에 올리지 않습니다.
