# 학생회관 회의실

- 마을 우측 상단 학생회관의 노란 문 표시 앞에서 **E**를 누르면 회의실에 들어간다.
- 회의실 하단 출구 가까이에서 **E**를 누르면 학생회관 문 앞으로 나온다.
- 옵션 → 조작키에서 `문 열기 / 상호작용` 키를 바꿀 수 있다.
- 플레이어마다 독립적으로 출입한다. 자전거는 입장할 때 자동으로 내린다.
- 내부에는 바닥, 벽, 회의 테이블, 의자, 출구를 도형으로 배치했다. 테이블과 벽은 통과할 수 없다.
- 회의실에서는 마을 지도와 자전거를 사용하지 않는다. 마을 지도를 보는 사람에게 내부 플레이어는 학생회관 위치에 `회의실` 표시로 나타난다.
- 같은 회의실의 음성은 거리와 무관하게 들린다. 마을과 회의실 사이의 음성은 차단한다.

## 구현 구조

`CapDetailedTown`이 학생회관 건물 데이터에서 문 앞 위치를 계산한다. `CapNetworkPlayer.InteractDoor()`가 소유자 전용 RPC를 호출하면 방장이 거리, 현재 공간, 지도 상태, 연속 입력 간격을 검사한다. 유효한 경우 `InMeetingRoom`을 변경하고 NetworkTransform으로 이동시킨다.

`CapMeetingRoom`은 마을과 떨어진 좌표에 내부 공간을 만든다. 네트워크 씬 전체를 교체하지 않고 각 플레이어의 공간 상태로 배경과 캐릭터 표시를 선택하므로 한 사람만 들어가도 나머지는 마을에 남을 수 있다. 카메라는 기존처럼 본인을 따라간다. 방장은 공간별 충돌 규칙을 적용한다.

회의실 출입은 조사 종료나 자동 회의 시작을 뜻하지 않는다. 이번 기능의 범위는 내부 이동과 공간 구분이다.

네트워크 데이터가 추가되어 프로토콜 버전은 3이다. 참가자 모두 같은 최신 빌드를 사용한다.

## 검증

개발 빌드의 `--meeting-verify`와 방장의 `--meeting-host` 플래그는 Relay/Vivox 두 클라이언트로 출입, 거리 제한, 지도 중 출입 차단, 내부 충돌, 원격 상태 동기화, 공간별 음성, 복귀를 검증한다. 이 모드에서는 마이크를 전송하지 않는다.
