# 도형 기반 멀티플레이 프로토타입

기존 마을 그림과 캐릭터 그림을 제거하고 단색 도형으로 동작을 확인하는 버전입니다.

## 실행

1. `CAP > 새 마을 대기실 열기` 또는 `Scenes/CapRelayTest.unity`를 엽니다.
2. Play 후 인터넷 방을 만들거나 참가 코드를 입력합니다.
3. 방장이 게임 시작을 누르면 모두 도형 마을로 이동합니다.
4. WASD/방향키 이동, M 전체 지도, B 이동 속도 전환을 사용할 수 있습니다.
5. 방장의 대기실로 돌아가기 버튼으로 모두 복귀합니다.

맵은 실행 시 만들어지므로 편집 중인 대기실 씬에는 보이지 않습니다. NPC 조사, 사건 진행은 이 버전에 구현되어 있지 않습니다.

## 구성

- 건물: 이름이 표시된 색 사각형. 표시된 영역과 충돌 영역이 같습니다.
- 플레이어: 4가지 색의 사각형. 게임 화면의 중앙을 따라갑니다.
- 도로/인도/공원: 단색 사각형. 기존 마을의 배치와 화면 배율을 유지합니다.
- TestSquare.png: 기존 대기실과 플레이어 프리팹이 참조하는 흰색 정사각형입니다. 일러스트가 아닙니다.

## 수정할 곳

- `Resources/Blockout/layout.json`: 건물 이름, 위치, 크기, 도로 위치. 단위는 기존 배치 좌표이며 50 = Unity 1유닛입니다.
- `Runtime/CapDetailedTown.cs`: 위 좌표를 사각형과 충돌 영역으로 만드는 부분입니다.
- `Runtime/CapWarmTown.cs`: 대기실/마을 표시 전환, 카메라, 이동 충돌 처리입니다.
- `Runtime/CapNetworkPlayer.cs`: 입력을 방장에게 보내고 방장이 이동을 계산합니다.
- `Runtime/CapRelaySession.cs`: 기존 인터넷 방 생성/참가 기능입니다.

GitHub Desktop에서 변경을 확인하고 Commit, Push해야 원격 저장소에도 반영됩니다. 기존 그림의 이전 커밋 기록은 남습니다.

## 전체 화면과 지도

게임 화면은 현재 Game 뷰의 가로세로 비율에 맞춰 전체를 채웁니다. 플레이어는 화면 중앙을 따라갑니다.
M으로 지도를 열면 별도의 정적인 마을 이미지와 플레이어 위치 아이콘을 표시합니다. M, Esc 또는 닫기 버튼으로 돌아옵니다.
지도를 연 사람은 로컬 입력과 방장 서버 양쪽에서 이동이 잠깁니다. 다른 플레이어의 이동은 계속되며 아이콘으로 실시간 반영됩니다.
배경 이미지는 플레이어를 제외한 맵을 별도 카메라로 한 번 촬영해 재사용합니다. 게임 카메라의 배율을 바꾸지 않습니다.
CapTownMap.cs: 지도 이미지 생성, 화면 표시, 위치 아이콘 좌표 변환.
CapNetworkPlayer.cs의 ViewingMap: 서버가 관리하는 지도 열림 및 이동 잠금 상태.

## 시작 화면

Play를 누르면 대학생 탐정단 시작 메뉴가 표시됩니다.
- 방 만들기: 기존 Relay 서비스에 인터넷 방을 만들고 대기실로 이동합니다.
- 방 참가하기: 참가 코드를 입력하고 연결하면 대기실로 이동합니다. 빈 코드는 접속 요청 전에 안내합니다.
- 옵션: 전체 음량, 창 모드/전체 화면 설정. 돌아갈 때 PlayerPrefs에 저장합니다. Unity 에디터에서는 화면 모드 변경을 비활성화합니다.
- 게임 종료: 실행 파일을 종료합니다. Unity 에디터에서는 Play 모드만 종료합니다.

대기실에서 방장이 게임 시작을 누르면 마을로 이동하고, 방을 나가면 시작 메뉴로 돌아옵니다.
시작 메뉴의 화면 구성과 버튼 연결은 Runtime/CapLobbyUI.cs에 있습니다. 네트워크 접속은 CapRelaySession.cs가 담당합니다.
