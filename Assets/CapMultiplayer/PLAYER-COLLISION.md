# 플레이어 간 충돌

대기실, 마을, 회의실에서 같은 공간에 있는 플레이어끼리 통과하지 못한다. 상대를 밀어내지는 않으며, 막힌 방향을 피해 옆으로 이동할 수 있다.

`CapPlayerCollision.cs`는 현재 도형 캐릭터의 실제 표시 크기(가로 1.206, 세로 1.8 유닛)에 작은 간격을 더한 사각형으로 충돌을 판정한다. 추후 캐릭터 그림을 교체하면 `BodySize`를 함께 검토한다.

플레이어는 이동 입력을 방장에게 보낸다. 방장은 기존 지형 충돌을 적용하고 다른 플레이어를 넘지 않도록 가로·세로 이동량을 제한한 뒤 결과 위치를 동기화한다. 이동을 작은 간격으로 나눠 자전거 속도에서도 통과하지 않도록 했다. Unity 물리엔진이 각 클라이언트에서 따로 플레이어를 밀어내는 방식은 사용하지 않는다.

게임 시작, 대기실 복귀, 재접속 및 학생회관 출입 때는 목적지 주변의 지형과 다른 플레이어를 검사해 빈 위치를 선택한다. 회의실과 마을처럼 다른 공간의 플레이어끼리는 충돌하지 않는다.

개발 빌드의 `--collision-verify --collision-role 0`부터 `3`까지 네 프로세스는 로컬 포트 17983에서 실제 NGO 연결로 검증한다. 정면 충돌, 비켜가기, 네 명의 자전거 충돌, 회의실 입장·퇴장 위치, 재접속 위치를 확인한다. 일반 실행의 Relay 접속 방식은 그대로 유지한다.
